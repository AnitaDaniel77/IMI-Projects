Capstone Project - Setting up Components and Routing

Exercise: Components and Navigation

Scenario

With the visual foundation done, this exercise adds actual routing and reusable components - so the same Nav, for example, works across the homepage, About page, and Bookings page instead of being rebuilt per page.

Step 1 - Components mapped from the Figma design

  • Nav (navbar) - already built
  • CallToAction / Hero - already built (currently called Header)
  • Homepage - the page that assembles Hero + Specials + Testimonials + About together
  • Specials - already built, currently living inside Main
  • CustomersSay (testimonials) - not yet built
  • Chicago (about section) - already built, currently living inside Main
  • BookingPage - not yet built - the actual reservations page

Real-life example: mapping Figma to components 1-to-1 is like translating a floor plan into an actual building's rooms - each labeled space on the drawing becomes one real, buildable room, not something improvised on-site.

Step 2 - Adding real navigation with react-router-dom

npm install react-router-dom
# adds React Router - the library that makes Link and Routes
# available; without it these are just undefined imports

import { Link } from 'react-router-dom';
// Link renders an actual <a> tag under the hood, but intercepts
// the click so React swaps pages WITHOUT a full browser reload -
// that's the core benefit over a plain <a href>

function Nav() {
  return (
    <nav>
      <ul>
        <li><Link to="/">Home</Link></li>
        <li><Link to="/about">About</Link></li>
        <li><Link to="/reservations">Reservations</Link></li>
      </ul>
    </nav>
  );
}

import { Routes, Route } from 'react-router-dom';
// Routes looks at the current URL and renders whichever Route's
// path matches it - like a switch statement for pages

function Main() {
  return (
    <Routes>
      <Route path="/" element={<Homepage />} />
      <Route path="/reservations" element={<BookingPage />} />
    </Routes>
  );
}

Real-life example: Routes/Route work like a hotel's floor directory - the URL is the room number you typed into the elevator panel, and the router sends you straight to the matching floor without you needing to walk through every other room first (a full page reload).
