Booleans

Course: Coding Interview Preparation — Module 2

What a Boolean is

A value that's either true or false — the binary equivalent being 1 or 0. Simple on its own, but combined with conditionals and logical operators it can drive surprisingly complex decision-making.

Relational operators

OperatorMeaning
>Greater than
<Less than
>=Greater than or equal to
<=Less than or equal to
==Equal to
!=Not equal to

These let code interrogate data before choosing which branch to run — hence Boolean expressions are often called conditionals.

Conditional statements

if, elif/else if, else, while. A conditional block runs one set of instructions under one condition, a different set under another.

if right > wrong:
    doTheRightThing()
elif wrong > right:
    doTheWrongThing()
else:
    keepResearching()

The final else acts as a catch-all when no earlier condition matched.

Real-life analogy: a Roomba deciding what to do — its "right vs wrong" is really "did a sensor detect a wall or an obstacle," triggering different motor responses.

Logical operators

OperatorMeaning
||Logical OR
&&Logical AND
!Logical NOT

Combining these with Boolean expressions expands what a single condition can check:

if condition_1 || condition_2:
    doActionOne()
elif condition_1 && condition_2:
    doActionTwo()
elif !condition_1:
    doActionFour()
else:
    waitForInstruction()

Roomba example: proximity OR impact detection → stop and reverse. Proximity AND impact → trigger an alarm. No proximity detected → keep driving forward. None of the above → fail-safe code kicks in.

Boolean logic in circuit design

Logic gates (AND, NOT, OR, NAND) are physical implementations of these same operators — a signal travels through wires, and a gate only "fires" when its Boolean condition is met. AND: both input wires must be true to continue the signal. NAND: only fires when both inputs are false. Combined, these gates let a device make complex decisions purely from sensor input, without software.

Key takeaway

Two values — true/false — seems limiting on its own, but stacked with conditionals and logical operators, Booleans become the backbone of both program control flow and physical circuit design.
