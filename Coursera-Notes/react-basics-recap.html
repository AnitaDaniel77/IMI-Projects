What is React?

React is a declarative, component-based JavaScript library for building user interfaces - built and composed component by component.

Real-life example: composability is like building with toy blocks - complex structures come from combining simple, individual pieces, not from one giant single piece trying to do everything.

Naming components

function Header() {
  // Capitalized name - this tells JSX "this is a custom
  // component," not a plain HTML tag
  return <header>Little Lemon</header>;
}

Capitalization is the actual mechanism JSX uses to tell components apart from regular HTML elements - lowercase means a built-in tag (like <div>), capitalized means a custom component.

Parent and child components

import Header from './Header';
// App imports Header -> App is the "parent" here,
// Header is the "child" once it's rendered inside App

function App() {
  return (
    <div>
      <Header />
    </div>
  );
}

Real-life example: parent/child here works like a restaurant's org chart - App is the manager who decides which staff (components) are on shift and in what order, but doesn't do their individual jobs itself.

Props vs. state

// Props: data passed IN from a parent - read-only from the
// child's perspective, can't be changed by the child itself
function Greeting(props) {
  return <p>Hello, {props.name}</p>;
}

// State: data that lives INSIDE a component, and that
// component can change it itself
import { useState } from 'react';

function Counter() {
  const [count, setCount] = useState(0);
  return <button onClick={() => setCount(count + 1)}>{count}</button>;
}

Real-life example: props are like a delivery you receive from someone else - you can use it, but you don't get to alter what was sent. State is like your own notebook - it's yours, and you're the one allowed to write in it.

Event handlers - HTML vs. React syntax

<!-- Plain HTML: lowercase, uses parentheses to call the function -->
<button onclick="handleClick()">Click me</button>

{/* React: camelCase, passes a reference to the function -
     no parentheses, or it would call the function immediately
     on render instead of waiting for the actual click */}
<button onClick={handleClick}>Click me</button>

Real-life example: the parentheses difference is like the difference between handing someone a phone number to call later versus dialing it yourself right now - onClick={handleClick} hands over the reference for React to call later, on click; onClick={handleClick()} would dial it immediately during render.
