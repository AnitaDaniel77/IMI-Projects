Reading: Recap - Styling Elements

Default CSS styling

Even with zero CSS written, a browser still displays HTML - it ships with pre-built styles for every single tag. Block elements like <h1>-<h6>, <p>, and <div> already come with display: block set by default. Nothing on a page appears with zero CSS - the browser is always applying something, even if it's invisible to you as the developer.

Real-life example: this is like a rental apartment that comes with basic furniture already in it - even before you move anything in yourself, it's not an empty shell; there's a default layout the landlord (the browser) already set up.

Practical CSS styling - overriding the defaults

.container {
    display: grid; /* no HTML element is display: grid by
                       default - this line switches it on,
                       overriding the browser's own default
                       (which would otherwise be display: block
                       for a div) */
}

Writing your own CSS is really just overriding specific defaults, not building styling from nothing. You keep everything the browser already gives you, and only change what you actually need to.

CSS selectors - precision matters

/* Bad - targets EVERY div on the entire page */
div {
    display: grid;
}

Real-life example: styling by element tag alone is like giving an instruction to "everyone wearing a shirt" when you only meant to talk to one specific person - it's technically true for them, but it also applies to everyone else in the room.

/* Good - only targets divs with this specific class */
.grid-container {
    display: grid;
}

<div class="grid-container">
  <!-- only this div gets the grid styling -->
</div>

Real-life example: a class selector is like addressing a letter to a specific name instead of just "resident" - it reaches exactly who it's meant for, and nobody else.
