Capstone Project - Setting up the CSS Layout

Exercise: Responsive CSS Grid/Flexbox Layout

Scenario

Little Lemon visitors will view the site on everything from phones to desktops, so the layout needs to be responsive - not just built once for a laptop screen and left to break on smaller devices.

Step 1 - Decide Grid vs Flexbox per section

Not every section needs the same tool. The rule of thumb from the recap: Grid for two-dimensional layouts (rows AND columns together), Flexbox for one-dimensional ones (a single row or column that just needs to wrap or align).

  • Hero, Specials cards, About section - already Grid, since these have real column structure
  • Nav bar, Footer link groups - good Flexbox candidates, since they're really just a row of items that needs to align and wrap

Step 2 - Add responsive breakpoints

The part that was missing before: none of the existing CSS had a way to adapt when the screen gets narrower. A media query is the fix - it lets a rule apply only below a certain width.

/* Default: desktop layout, 3 columns */
.specials__cards {
    display: grid;
    grid-template-columns: repeat(3, 1fr);
    gap: 30px;
}

/* Tablet and below: drop to 2 columns */
@media (max-width: 900px) {
    .specials__cards {
        grid-template-columns: repeat(2, 1fr);
    }
}

/* Mobile: stack into a single column */
@media (max-width: 600px) {
    .specials__cards {
        grid-template-columns: 1fr;
    }
}

Real-life example: a media query is like a store rearranging its shelves for a smaller shop - the same products (content) get displayed, just in a layout that fits the space available.

Step 3 - Verify in the browser

  1. Run npm start
  2. Open localhost:3000
  3. Open DevTools (F12), toggle the device toolbar (responsive mode), and drag through different widths
  4. Confirm nothing overlaps, text doesn't get cut off, and images scale down instead of overflowing

Applied to Little Lemon

Since the actual Little Lemon project already has Grid set up for hero/specials/about, this exercise is really about adding the missing breakpoints and converting the nav/footer to Flexbox, rather than starting from scratch.
