Stacks and Queues in Different Programming Languages

Course: Coding Interview Preparation — Module 2

Abstract data types

Both stacks and queues are abstract data types — there's no built-in version to just import. Certain behaviors must be enforced, but implementation is up to you.

Stacks — LIFO

Real-life analogy: a pile of plates on a washing board — each clean plate goes on top, and drying starts from the top down. The last plate placed is dried first; the first plate placed is dried last.

Real-world use: browser history. Hitting back loads the previously visited page, then adds it back onto the "forward" pile.

JavaScript implementation — container adapters

A common JS approach builds a stack using an array as the underlying container, restricting it to only behave like a stack. Using one data structure to build another this way is called a container adapter — the array is the container, and the adaptation forces stack-like behavior onto it.

Core methods: push (add to top), pop (remove from top), peek (view top without removing), count (tracks where the last item sits in the array, needed for both push and pop to work correctly).

Queues — FIFO

Also linear, also strict about how items are added/removed — but first-in-first-out instead of last-in-first-out.

Real-life analogy: a checkout queue — first person in line is served first, importance placed on arrival time.

Real-world use: CPU and disk scheduling — tasks handled in arrival order.

Swift implementation

Queue is also abstract in Swift — you build the structure yourself. Key terms: enqueue (add an item), dequeue (remove from the front). Simplest build: array as container adapter. Because queues only pop from the front, lookup time is a reliable O(1).

Core methods: peek, pop, push, size.

Python implementation — synchronization and priority queues

Python's queue classes are synchronized — access is managed so only one process touches the data at a time. Important for concurrent/cloud scenarios where multiple sources might read/write simultaneously.

Beyond standard FIFO/LIFO, Python also offers a priority queue — service order is based on assigned importance rather than arrival order.

Real-life analogy: the VIP line at a concert — skips the first-come-first-served rule entirely in favor of who matters more for that queue's purpose.
