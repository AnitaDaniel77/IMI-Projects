Meta Front-End Capstone: Little Lemon Reserve a Table

Module 1 - Starting the Project

Project brief

Little Lemon is a family-owned Mediterranean restaurant. The capstone asks for a "reserve a table" booking app built in React, covering the full front-end workflow from planning through deployment across the four modules: starting the project, project foundations, project functionality, and project assessment.

What this module covers

  • Defining the app's purpose and user stories (a guest wants to book a table for a given date, time, and party size)
  • Setting up the project with a scaffolding tool
  • Planning the component structure before writing code
  • Deciding on state management approach for the booking form

Scaffolding

npx create-react-app little-lemon
# create-react-app scaffolds a full React project with a dev
# server, build tooling, and testing all wired up already

cd little-lemon
npm start
# starts the dev server at localhost:3000 and auto-reloads
# whenever a file is saved

Real-life example: create-react-app is like ordering a furnished apartment instead of building one brick by brick - the wiring, plumbing, and structure are already done, you just move your own things in.

Initial state design

import { useReducer } from "react";
// useReducer manages state through a function (a "reducer")
// instead of many separate useState calls - useful here since
// booking times depend on which date is picked

function updateTimes(state, action) {
  switch (action.type) {
    case "UPDATE_DATE":
      return fetchAPI(action.date); // new date picked -> fetch
                                     // that date's available times
    default:
      return state; // unrecognized action - state stays the same
  }
}

const initializeTimes = () => fetchAPI(new Date());
// runs once on first render, loading today's available times
// before the user has picked anything

Real-life example: think of the reducer like a restaurant host's booking sheet - every time someone asks for a different date, the host doesn't throw out the whole sheet, they just look up that date's open slots and hand back the relevant page.
