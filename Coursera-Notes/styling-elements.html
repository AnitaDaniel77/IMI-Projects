Capstone Project - Styling Elements

Exercise: Applying Visual Styles from the Figma Design

Scenario

With the layout in place, this exercise is about the visual details - font sizes, spacing, line height, colors, backgrounds, borders - matching what was actually designed in Figma, not just structural positioning.

Design questions worth answering first

  • Common theme: Mediterranean restaurant - warm, earthy, food-forward
  • Colors: already defined as CSS variables - green, yellow, peach, cream
  • Font sizes: Markazi Text for display/headings (large, serif), Karla for body/nav (smaller, sans-serif)
  • Border radius: rounded, not sharp - the Figma cards and images all use rounded corners (16px), not 0
  • Shadows: the Figma design doesn't show drop shadows on cards - flat design with color/spacing doing the visual separation instead

Step 2 - Base heading, paragraph, and span styles

h1, h2, h3, h4, h5, h6 {
    font-family: var(--font-display); /* every heading defaults
                                           to the display font,
                                           not just specific ones */
    margin: 0; /* removes the browser's default heading margin -
                   spacing is controlled per-section instead */
    color: var(--color-highlight-dark);
}

p {
    font-family: var(--font-body);
    line-height: 1.5; /* comfortable reading spacing between
                          lines, applied everywhere by default */
    color: var(--color-highlight-dark);
}

span {
    font-family: inherit; /* spans take on whatever font their
                              parent element already has, unless
                              overridden - keeps inline text
                              consistent with its surroundings */
}

Real-life example: setting these at the element level (not a class) is like painting the walls of every room the same base color before adding individual furniture - it's the shared foundation everything else sits on top of.

Step 3 - Navigation elements

nav {
    font-family: var(--font-body);
}

nav ul {
    list-style: none; /* removes the default bullet points -
                          browsers add these to every ul/li
                          automatically */
    margin: 0;
    padding: 0;
}

nav li {
    display: inline-block; /* makes list items sit side by side
                                instead of stacking vertically,
                                which is the 
  •  default */
}

    • Step 4 - Images

    img {
    max-width: 100%; /* images never overflow their container,
                          regardless of their original size */
    display: block; /* removes the small gap browsers leave
                         under inline images by default */
    border-radius: 16px; /* matches the Figma design's rounded
                              corners - nothing in this project
                              uses sharp 0px corners */
}

    Real-life example: max-width: 100% on images is like framing a photo to fit the wall space you have, rather than hanging an oversized print that spills past the frame's edges.

    Step 6 - Verify

    1. Run npm start
    2. Check headings, paragraphs, nav, and images all read correctly at desktop width
    3. Switch to responsive mode in DevTools and re-check at mobile width

    Note from the lesson: this step often gets revisited repeatedly as the app develops further - it's not a one-time pass.
