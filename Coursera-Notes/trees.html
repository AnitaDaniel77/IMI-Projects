Trees

Course: Coding Interview Preparation — Module 2

What a tree is

A non-linear structure made of connected nodes. A node with children is a parent; a node with no children is a leaf. Nodes are linked by edges that model their relationships.

Terminology

  • Root: the top-level node
  • Child: a node connected below another
  • Siblings: nodes sharing the same parent, on the same level
  • Path: a series of connected nodes; the shortest path between two nodes suggests how closely related they are
  • Depth: number of edges from a node up to the root
  • Height: number of edges from the topmost node down to the deepest node
  • Size: total number of nodes in the tree

Real-life analogy: a book's table of contents — chapters are top-level nodes, subsections are their children, and sub-subsections branch further down. Sections under the same chapter (siblings) tend to share a theme; sections in different chapters are more loosely related.

Types of trees

Binary trees, B trees, B+ trees, Quad trees, AVL trees, among others — all share the general node/edge structure, but differ in implementation and use case.

Binary trees — ordering rule

Left node = lesser value, right node = greater value. Worked example inserting 23, 4, 1, 30, 24, 56:

  • 23 → root
  • 4 → less than 23 → left of 23
  • 1 → less than 23 and less than 4 → left of 4
  • 30 → greater than 23 → right of 23
  • 24 → less than 30 → left of 30
  • 56 → greater than 30 → right of 30

Traversal methods

  • Depth-first: visit nodes top to bottom, sequentially down a branch
  • Breadth-first: visit every node on the current level before moving to the next level down

Why use a tree

  • Node connections naturally reflect relationships in the data
  • Supports hierarchical storage — general info at the top, more specific info deeper down a branch
  • Efficient insertion and deletion thanks to flexible structure
  • Multiple traversal strategies suit different search needs

Real-world uses

File systems on a computer, Java class hierarchies, organizational hierarchies within a company.
