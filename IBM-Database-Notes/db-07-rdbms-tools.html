RDBMS Tools

Acronyms

  • RDBMS: Relational Database Management System.
  • GUI: Graphical User Interface, a tool you click around in.
  • CLI: Command Line Interface, a tool you type commands into.
  • IDE: Integrated Development Environment, like VS Code or IntelliJ.
  • DBA: Database Administrator, the person who looks after the database servers.
  • ER diagram: Entity-Relationship diagram, a picture of the tables and how they link.

Why tools matter

SQL is the language, but tools make it easier to design tables, run queries, see results, and manage the server.

Real-life example: you can count cash by hand, but a note counter is faster and makes fewer mistakes. Same job, better tool.

GUI tools

  • MySQL Workbench (free): for MySQL. Schema design, SQL editor, data modelling and server settings. Good for beginners.
  • pgAdmin (free): for PostgreSQL. Visual query tool, server dashboard and user roles.
  • DBeaver Community (free): works with almost any database (MySQL, PostgreSQL, SQLite, Oracle, SQL Server). ER diagrams, import and export.
  • HeidiSQL (free, Windows): light and fast, mainly for MySQL and MariaDB.
  • TablePlus (paid, limited free trial): polished and fast, supports many databases.

Real-life example: a GUI tool is like using the banking app instead of USSD codes. You see everything laid out and click through it.

CLI tools (all free)

  • mysql: MySQL's terminal client. Run SQL, back up with mysqldump, and manage users.
  • psql: PostgreSQL's terminal client, with tab-completion and query history.
  • sqlite3: shell for SQLite files. No setup at all, so it's great for quick tests.

Best for automation, scripts, and remote or cloud servers where there's no screen to click on, like the Coursera Cloud IDE labs.

Real-life example: USSD on an old phone. No visuals, but it works anywhere and it's quick once you know the codes.

IDE database tools

  • VS Code (free): add the SQLTools extension plus its MySQL or PostgreSQL driver, or SQLite Viewer. You can write Java and run SQL in the same editor.
  • IntelliJ IDEA: the database tools are only in the paid Ultimate edition, not the free Community edition.
  • DataGrip: JetBrains' full database IDE. Check the current licence, because it's paid for commercial use.

Which tool for which job

  • MySQL schemas: MySQL Workbench or DBeaver.
  • PostgreSQL: pgAdmin or DBeaver.
  • Many different databases: DBeaver.
  • Quick and light: HeidiSQL or sqlite3.
  • Remote servers and scripts: mysql or psql.
  • Inside your editor: VS Code with SQLTools.

My free setup

VS Code with SQLTools for day-to-day work, DBeaver Community when I want ER diagrams or to browse data, and the mysql CLI in the Coursera labs. The reading's advice is to know at least one GUI and one CLI tool.

Pseudocode: what every tool does when you connect


ASK for host, port, database name, username, password
OPEN a connection using the right driver
IF connection fails
    show the error (wrong password, server off, no driver)
ELSE
    read the database details (name, version)
    list the tables in the sidebar
    let the user run SQL and show results in a grid

Tips for understanding the logic

  • All these tools send the same SQL to the same database. They only differ in how you type it and how they show the results.
  • "No suitable driver" means Java or the tool doesn't have the connector for that database installed.
  • Port 3306 is MySQL's default, and 5432 is PostgreSQL's.
