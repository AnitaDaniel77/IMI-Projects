Module 4: Java Date and Time Classes

Why date and time handling matters

Any real application eventually needs to work with dates or times, logging when something happened, scheduling an event, just showing today's date. Java handles all of this through the java.time package, a modern replacement for the older, clunkier Date and Calendar classes.

Real-life example: a calendar app, a logging system, even just a clock widget, all of them need a reliable, consistent way to read and display dates and times, that's exactly what java.time provides.

LocalDate — just the date

Retrieves a date in year, month, day format, no time, no timezone. Good for anything where only the calendar date matters.

Real-life example: a birthday. You care that it's the 14th of March, not what time of day it currently is or what timezone you're in.

import java.time.LocalDate

today = LocalDate.now()          // pulls the current date from the system clock
print "Today's Date: " + today  // format: YYYY-MM-DD

LocalTime — just the time

Retrieves hours, minutes, seconds, no date, no timezone awareness.

Real-life example: setting an alarm clock or timing a race, you only care about the clock reading, the date and timezone are irrelevant to the task.

import java.time.LocalTime

now = LocalTime.now()
print "Current Time: " + now

LocalDateTime — date and time together

Combines both LocalDate and LocalTime into one, still no timezone.

Real-life example: scheduling a meeting with people in the same office, down the hall, same timezone, so there's no need to track one separately.

import java.time.LocalDateTime

now = LocalDateTime.now()
print "Current Date and Time: " + now   // includes hours, minutes, seconds, nanoseconds

ZonedDateTime — date, time, and timezone

Adds timezone awareness on top of date and time, the only one of the four that knows where in the world it is.

Real-life example: an airline flight schedule or a meeting across multiple timezones, you can't coordinate those without knowing which timezone each time belongs to.

import java.time.ZonedDateTime

now = ZonedDateTime.now()
print "Current Date, Time, and Zone: " + now   // format: yyyy-MM-dd HH:mm:ss plus timezone

Choosing between them

Logic: ask what you actually need to track. Just a calendar date, LocalDate. Just a clock time, LocalTime. Both together but always in one place/timezone, LocalDateTime. Both together across different timezones, ZonedDateTime.

  • LocalDate: year, month, day only.
  • LocalTime: hours, minutes, seconds only.
  • LocalDateTime: date and time, no timezone.
  • ZonedDateTime: date, time, and timezone.

All four follow the same pattern: import the class, call its now() method to pull the current value from the system clock, then print it with a label.
