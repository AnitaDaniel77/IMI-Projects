LocalDate and LocalTime: getting the current date/time

LocalDate and LocalTime live in the java.time package, each handling one half of the picture, LocalDate just the calendar date, LocalTime just the clock reading. Both have a static now() method that pulls straight from the system clock, no need to construct an instance manually.

Real-life example: a wall clock only shows the time, a calendar only shows the date, LocalTime and LocalDate are that same split, each one doing a single job rather than trying to cover both.

Logic: now() is a static method, called on the class itself (LocalDate.now()), not on an instance, because there's nothing to configure, it just asks the system clock what time it is right now.

import java.time.LocalDate
import java.time.LocalTime

print "The date is " + LocalDate.now()
print "The time is " + LocalTime.now()
