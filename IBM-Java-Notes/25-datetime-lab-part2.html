Module 4: Format a Given Date and Time (Lab, Part 2)

Letting the user choose the format

Part 1 printed the date and time in Java's default format. This part lets the user type their own pattern, dd/MM/yyyy, HH:mm:ss, whatever they want, and the program builds a DateTimeFormatter from that input and applies it.

Logic: DateTimeFormatter.ofPattern() takes a pattern string and turns it into a formatter object, then calling format() on a date/time with that formatter produces the string in that shape. Same two-step process every time, build the formatter, apply it.

LocalDateTime: the third piece

Alongside LocalDate and LocalTime from Part 1, this lab introduces LocalDateTime, which holds both the date and the time together in one object.

Real-life example: a calendar invite needs both, "the 14th" alone isn't a meeting, neither is "3pm" alone, LocalDateTime is the combined "14th at 3pm."

Pattern letters used here

  • Date: dd (day), M/MM/MMM/MMMM (month as number, padded number, short name, full name), yy/yyyy (2 or 4-digit year).
  • Time: H/HH (24-hour, padded), h/hh (12-hour, padded), m/mm (minute, padded), s/ss (second, padded).

Logic: lowercase vs uppercase and single vs doubled letters change the output, "M" gives a bare month number, "MM" zero-pads it, "MMM" spells the abbreviation, "MMMM" spells it out in full, worth testing a pattern once before relying on it.

Reading a custom format from the user

today = LocalDate.now()
read formatInput from user          // e.g. "dd MM yy"
formatter = DateTimeFormatter.ofPattern(formatInput)
print "The date is " + today.format(formatter)

now = LocalTime.now()
read timeFormatInput from user      // e.g. "hh:mm:ss"
timeFormatter = DateTimeFormatter.ofPattern(timeFormatInput)
print "The time is " + now.format(timeFormatter)

nowDateTime = LocalDateTime.now()
print nowDateTime                   // default format first, for comparison
read dateTimeFormatInput from user  // e.g. "yyyy, dd MMM hh:mm"
dateTimeFormatter = DateTimeFormatter.ofPattern(dateTimeFormatInput)
print "The date and time is " + nowDateTime.format(dateTimeFormatter)

Real-life example: typing "dd MM yy" turns 2026-10-02 into "02 10 26", typing "yyyy, dd MMM hh:mm" turns the same moment into "2026, 02 Oct 11:44", same underlying date and time, the pattern is just a different lens on it.
