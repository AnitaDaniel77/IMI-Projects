Building Blocks of Java Programming — Glossary

Official course glossary for Module 2 of IBM's Java Developer Professional Certificate. Kept alongside numbered lesson notes for quick lookup. Several terms here (String methods, Scanner, static, this/super) preview upcoming lessons.

TermDefinition
ArrayListA resizable implementation of the List interface — grows/shrinks dynamically, unlike a fixed array.
charAt methodReturns the character at a specific index in a string.
ConstructorSpecial method that initializes new objects.
EncapsulationRestricting access to certain class details, exposing only what's necessary.
equals methodCompares the values of two strings or objects for equality.
extends keywordUsed by a class to indicate it's inheriting from another class.
InheritanceA class acquiring the properties/methods of another class.
InterfaceA collection of abstract methods a class can implement.
length methodReturns the length of a string or an array.
Math classProvides mathematical functions like sqrt, pow, abs.
nextInt / nextLineScanner methods for reading integer input / a full line of text input.
null keywordRepresents the absence of a value in an object reference.
OverloadingDefining multiple methods with the same name but different parameters.
OverrideDefining a method in a subclass that replaces the parent class's version.
parseInt / parseDoubleConvert a string into an int / double.
PolymorphismAn object taking multiple forms, usually via method overriding/overloading.
private / public access modifierprivate: only accessible within the same class. public: accessible from anywhere in the application.
Random classUsed to generate random numbers.
Scanner classUsed to take input from the user.
split methodSplits a string into an array based on a given delimiter.
Static method / variableBelongs to the class itself rather than any one instance.
substring methodExtracts part of a string based on given indexes.
super keywordRefers to the parent class of the current object.
this keywordReferences the current instance of a class.
throw / throws keywordthrow: manually raises an exception. throws: declares in a method signature that it may throw exceptions.
toLowerCase / toUpperCaseConverts a string to lowercase / uppercase.
Unchecked exceptionAn exception that doesn't require explicit handling.

Note: this is a representative excerpt of key terms. Terms already covered in depth (comments, packages, data types, operators, arrays) have full lesson notes in files 06-10 of this folder.
