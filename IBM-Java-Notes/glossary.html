Java Environment and Ecosystem — Glossary

Official course glossary for IBM's Java Developer Professional Certificate. Kept alongside the numbered lesson notes for quick lookup. Many of these terms are ahead of what's been covered so far (OOP, exceptions, collections) — useful as a preview of what's coming.

TermDefinition
Abstract classA class that cannot be instantiated, meant to be subclassed, often containing abstract methods subclasses must implement.
Access modifierKeyword defining scope/visibility of a class, method, or variable (public, private, protected).
APIRules and tools letting different software applications communicate.
ArrayFixed-size structure holding elements of the same type in contiguous memory.
AutoboxingAutomatic conversion of a primitive into its corresponding wrapper class object.
BytecodePlatform-independent code generated by the Java compiler, run by the JVM.
Casting / Type castingConverting one data type into another.
Checked exceptionAn exception that must be declared or handled with try-catch.
ClassBlueprint for creating objects — defines fields (attributes) and methods (behaviors).
ConstructorSpecial method initializing an object when a class is instantiated.
Data encapsulationRestricting direct access to object data, manipulated only through methods.
EnumA special type defining a set of named constants.
Exception handlingMechanism for handling runtime errors and keeping the program running smoothly.
Garbage collectionAutomatic reclamation of unused memory, preventing memory leaks.
Generic classA class that works with different data types using type parameters.
HashMapStores key-value pairs, enabling fast retrieval by key.
Heap memoryWhere objects are dynamically allocated at runtime.
Immutable objectAn object whose state cannot change after creation.
InheritanceA subclass deriving properties/behaviors from a parent class.
InterfaceBlueprint defining abstract methods that implementing classes must provide.
JDK / JRE / JVMDevelopment kit / runtime environment / virtual machine — the three core pillars of running Java.
Method overloadingMultiple methods, same name, different parameter lists, same class.
Method overridingRedefining a parent class's method in a subclass.
MultithreadingMultiple threads running concurrently.
NullPointerExceptionRuntime exception from accessing a null object reference.
ObjectAn instance of a class, encapsulating state and behavior.
PackageA namespace grouping related classes/interfaces.
PolymorphismAn object's ability to take multiple forms; methods callable across different object types.
Primitive data typeBasic types like int, char, float, boolean.
RecursionA method calling itself to solve a problem.
SerializationConverting an object into a byte stream for storage/transmission.
Stack memoryStores method call frames and local variables.
Static methodBelongs to the class itself, not to instances.
StringA sequence of characters — implemented as an immutable object in Java.
ThreadA lightweight process running concurrently with others.
try-catch blockHandles exceptions by catching errors and running alternative code.
Wrapper classAn object representation of a primitive data type.

Note: this is a representative excerpt of key terms for quick lookup. Terms already covered in depth (JDK/JRE/JVM, classes/objects, primitive types) have full lesson notes in files 01-05 of this folder and in SME-Java-Notes.
