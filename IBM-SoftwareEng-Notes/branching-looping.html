Branching and Looping Programming Logic

The two major types of programming logic

All programming logic boils down to two categories: branching (deciding what to do) and looping (deciding how many times to do it). Both rely on the same two building blocks: Boolean expressions and variables.

  • Boolean expression — a statement that only ever evaluates to true or false.
  • Variable — a value that can change depending on conditions or information passed into the program, used within functions or subroutines.

Computers use Boolean logic to decide between actions: take one path if a condition is true, a different path if it's false.

Branching

Branching is where a program follows a different set of instructions depending on whether certain conditions are met while it's running. Each possible pathway is a "branch," and there's no hard limit on how many branches a program can have to represent complex logic. The values that determine which branch runs can come from user input or from the output of an earlier step in the program.

Common branching constructs

  • if — executes one block of code if a condition is true.
  • if-then-else — extends `if` by guaranteeing something always runs: the true block or the false block, one or the other, always.
  • switch — lets the value of a variable/expression itself determine which path the program takes, mapping specific values to specific actions.
  • GoTo — a one-way jump straight to another line of code. Notably different from a function call, which returns control back to where it was called from.

Real banking example

Every if/else if/switch statement you've written in your Udemy course (login validation, FizzBuzz, day-name lookups) is branching logic in action — deciding *what action to take* based on a condition. Something like fraud detection at Capitec is fundamentally a massive branching structure: if transaction amount exceeds X, branch to a review flow; if location doesn't match the account's usual pattern, branch to an alert; otherwise, branch straight through to approval.

Looping

A loop is a sequence of instructions that repeats until a specific condition is reached. Typically: perform a process (like retrieving/updating data), check a condition (like whether a counter hit its target), and if not yet met, go back and repeat. Once the condition is satisfied, execution either falls through to the next instruction or exits the loop entirely.

The three basic loop types

  • While — condition checked *before* the loop body runs; the body only executes if the condition is true.
  • For — initial value set once, then the condition is checked against a counter after each pass, stopping once it evaluates false.
  • Do-while — condition checked *after* the loop body runs (an "exit-controlled" loop), guaranteeing at least one execution.

Logic to hold onto

The cleanest way to remember the split: branching is a decision about *direction* (which path to take), looping is a decision about *duration* (how many times to repeat one path). Nearly every program you'll ever write is built entirely from combinations of these two ideas layered on top of each other — an if statement inside a for loop, a switch inside a while loop, and so on.
