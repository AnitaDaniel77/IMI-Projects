Query and Assembly Programming Languages

High-level vs low-level

High-level languages use recognizable English-like syntax, making code easier to write, read, and debug. Examples: query languages (SQL), structured languages (Pascal), object-oriented languages (Python).

Low-level languages use a simpler set of symbols much closer to raw machine code. Examples: assembly languages (ARM, MIPS, x86).

Query languages

A query is a request for information from a database — the database searches its tables and returns results. Both the requesting application and the database need to speak the same query language for this to work. SQL (Structured Query Language) is by far the most common, though others exist (AQL, CQL, Datalog, DMX).

SQL vs NoSQL

  • SQL databases — relational, structured, predefined schema.
  • NoSQL databases (Not Only SQL) — non-relational, dynamic schema, built for unstructured data.

CRUD

Query languages are mainly used to request data or perform CRUD operations — Create, Read, Update, Delete. Query statements (also called "statements") fall into two types:

  • Select queries — request/retrieve data
  • Action queries — manipulate data (create, insert, update)

Statements can also handle admin tasks like creating users or modifying permissions, beyond just data operations.

Real banking example

Every time the Capitec app shows your transaction history, that's a SELECT query pulling rows from a transactions table. Every time you make a payment, an INSERT (or similar action query) writes a new row recording that transaction. Later in your syllabus (Java Development with Databases), you'll be writing exactly this kind of query from Java code rather than typing raw SQL by hand — but the underlying logic is the same CRUD pattern from this lesson.

Assembly languages

The least sophisticated category — a simple set of symbols representing the actual zeros and ones of machine code directly. Assembly is tightly tied to specific processor/CPU architecture, so each CPU type generally has its own assembly language (which is why many different assembly languages exist across hardware manufacturers).

Structure: statements are written one per line, made up of an instruction/mnemonic (like `LOAD`, `ADD`, `OUTPUT`) plus operands/parameters, with optional comments. Mnemonics map to opcodes telling the processor what to do, and operands tell it where to find the relevant data.

Key distinction: assembler vs compiler/interpreter

Assembly language is translated by an assembler, not a compiler or interpreter. The key difference: one assembly statement translates into exactly one machine code instruction (a 1:1 relationship), whereas one line of a high-level language can expand into multiple machine code instructions during compilation or interpretation.

Logic to hold onto

Think of this as a spectrum of distance from raw machine code. Assembly sits closest to the hardware — one line, one instruction, tied to a specific CPU. High-level languages like SQL or Python sit furthest away — closer to how a human thinks, with one line potentially unpacking into many machine instructions behind the scenes. Query languages are a special-purpose high-level language focused entirely on one job: talking to a database, rather than general-purpose programming.
