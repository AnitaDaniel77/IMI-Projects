Spring 06: Annotations

An annotation is a label on a class, method, field or parameter. It gives Spring metadata, so Spring knows how to create, wire and expose that piece of code without us writing the setup by hand.

Pseudocode

START application
  Spring scans packages for classes labelled @Component / @Service / @RestController
  FOR each labelled class
    create one object (a bean) and keep it in the IoC container
  FOR each constructor that needs other beans
    find the matching bean and pass it in (dependency injection)
  FOR each method labelled @GetMapping
    register the URL so HTTP requests reach that method
WAIT for requests

Common annotations

AnnotationWhat it does
@ComponentMarks a class as a Spring-managed bean, registered in the IoC container automatically.
@ControllerMarks a web controller in an MVC app. Handles HTTP requests and returns a view.
@RestController@Controller plus @ResponseBody. Returns data (JSON) straight to the client.
@AutowiredAsks Spring to inject a dependency. A single constructor does not need it.
@QualifierPicks which bean to inject when several of the same type exist.
@ConfigurationMarks a class as a source of bean definitions.
@BeanOn a method inside a @Configuration class. The return value becomes a bean.
@RequestMappingMaps HTTP requests to a class or method.
@GetMappingShortcut for a GET @RequestMapping.
@PathVariableReads a value from the URL path, like the id in /books/7.
@RequestParamReads a query parameter, like title in /search?title=Dune.
@ResponseBodyWrites the return value to the response body instead of looking for a view.
@ValueInjects a value from a properties file, environment variable or default.
@ScopeSets bean lifecycle. Singleton (default, one shared object) or prototype (new object per request for the bean).

Where they go

LevelExamples
Class@Component, @Service, @Repository, @Controller
Method@Bean, @RequestMapping, @GetMapping
Field@Autowired, @Value, @Qualifier
Constructor / parameter@Autowired, @Qualifier, @PathVariable, @RequestParam

For the Fraud Rule Engine

Each fraud rule gets @Component so Spring finds it. The service takes List<FraudRule> in its constructor. The controller is a @RestController with @PostMapping and @GetMapping methods. Thresholds such as the high-amount limit come from @Value, so they live in application.properties and not in the code.

Example

See spring-06-annotations/AnnotationsDemo.java. Run it inside a Spring Boot project, then:

curl http://localhost:8080/books/7
curl "http://localhost:8080/search?title=Dune"

Expected output:

Book 7 from City Library
Searching City Library for: Dune
