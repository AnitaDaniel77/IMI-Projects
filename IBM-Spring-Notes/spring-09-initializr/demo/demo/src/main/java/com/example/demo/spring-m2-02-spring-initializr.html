Using Spring Initializr for Spring Boot

IBM Spring Framework for Java Development, Module 2, Deep Dive into Spring Boot

What I should be able to do after this reading

  • Define Spring Initializr
  • Explain how to use it to create a Spring Boot project

What is Spring Initializr?

A free website (start.spring.io) where you tick the options you want and it builds a ready-to-use Spring Boot project as a ZIP file. You open that ZIP in your IDE (Integrated Development Environment, the program you write code in, like VS Code or IntelliJ).

Real-life example: ordering a pizza from a form. You choose the base, size and toppings, and a ready pizza arrives. For my fraud engine I picked my settings and got a project that already had a pom.xml, a main class and the right folders.

The steps

  1. Open start.spring.io in a browser
  2. Fill in the project metadata
  3. Choose the project options
  4. Add dependencies
  5. Press Generate and download the ZIP
  6. Extract the ZIP and open the folder in the IDE
  7. Run the application

Project metadata

  • Group: a reversed domain name you control, like com.example. Mine is com.anitadaniel.
  • Artifact: the project name, like demo. Mine is fraud-rule-engine.
  • Name: the display name
  • Description: one line about the project
  • Package name: the base package for the Java classes, normally built from group and artifact. Mine is com.anitadaniel.fraudengine.

Real-life example: like a postal address. The group is the street, the artifact is the house number, and the package is the full address that every class is filed under.

Project options

  • Project: Maven or Gradle (build tools that download libraries, compile and package the app). I use Maven.
  • Language: Java, Kotlin or Groovy. I use Java.
  • Spring Boot version: choose the latest stable release

Dependencies (the libraries you add)

  • Spring Web: web applications and RESTful services (REST stands for REpresentational State Transfer, a standard way for programs to talk over the web)
  • Spring Security: login and permissions (authentication and authorization)
  • Thymeleaf: a template engine that builds HTML pages

Real-life example: choosing apps when you set up a new phone. You only install what you need. My fraud engine needs web, data storage, validation and health checks, and no login yet.

Importing and running

  • IntelliJ: File, then Open, then choose the project folder. Find the class with the main method (for example DemoApplication) and press Run.
  • VS Code or terminal: go to the project folder and run ./mvnw spring-boot:run (Maven) or ./gradlew bootRun (Gradle)

Pseudocode

``` OPEN start.spring.io SET group, artifact, name, description, package CHOOSE project (Maven or Gradle), language, Spring Boot version FOR each library I need ADD it as a dependency CLICK Generate and DOWNLOAD the ZIP EXTRACT the ZIP and OPEN the folder in the IDE RUN the main class, or run ./mvnw spring-boot:run ```

Tips to understand it

  • Initializr only creates the starting point. After that it is a normal Maven project that I edit myself.
  • The dependencies you tick end up as lines in pom.xml. Added one by mistake? Delete its lines, or add one later by editing the pom.
  • The ./mvnw file is the Maven Wrapper. It means I do not need Maven installed, which is how my CI robot built the fraud engine.

Summary

  • Initializr is a web form that generates a Spring Boot starter project
  • Metadata names the project, options pick the tools, dependencies pick the libraries
  • Generate, extract, open in the IDE, run
