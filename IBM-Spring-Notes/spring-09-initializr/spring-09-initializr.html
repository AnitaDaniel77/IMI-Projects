Spring 09: Spring Initializr

What it is

Spring Initializr is a web tool at start.spring.io that generates a ready-to-run Spring Boot project. You choose the options and it builds the folder structure, the pom.xml and the main class for you.

Real-life example: ordering a meal kit. You pick the dish and the ingredients on a form, and a box arrives with everything measured and labelled, so you start cooking instead of shopping.

The options, in the order you meet them

  • Project: Maven or Gradle. We use Maven.
  • Language: Java, Kotlin or Groovy. We use Java.
  • Spring Boot version: pick the latest stable release (not a SNAPSHOT or milestone) to get current features and fixes.
  • Group: the organisation, written like a domain (com.example.course).
  • Artifact and name: the project name. The package name fills in by itself from group and artifact.
  • Packaging: JAR or WAR. JAR for Boot apps, because Boot has the web server built in.
  • Java version: choose one you have installed. I have 21, so I choose 21 even though the lesson shows 23.
  • Dependencies: the libraries you want. Spring Web builds web apps and REST APIs. Spring Data JPA gives database access.

Real-life example: group, artifact and package are your address on the parcel. The Java version is the oven size, so it must be one your kitchen actually has.

Explore and Generate

Explore shows the generated files in the browser so you can check the structure before downloading. Generate downloads a zip. Extract it and open the folder in your IDE as a Maven project.

What you get

  • pom.xml with the Spring Boot parent and the dependencies you chose.
  • A main class annotated with @SpringBootApplication. This is the entry point.
  • src/main/resources/application.properties for settings.
  • A test class in src/test/java.
  • mvnw, the Maven wrapper, so the project builds even without Maven installed.

Tips to understand it

  • The only thing you must remember: Initializr writes the pom.xml for you. Choosing a dependency on the website is the same as adding it to the pom by hand.
  • If something is missing later (no web server, no database), the first place to look is the dependencies list.
  • Pick Java 21 here, not the newest in the dropdown, or the build fails on a machine without that JDK.

Pseudocode

``` OPEN start.spring.io CHOOSE Maven, Java, latest stable Boot version SET group, artifact (package is filled in) CHOOSE packaging JAR and Java 21 ADD dependency Spring Web CLICK Generate -> download zip EXTRACT zip OPEN in IDE as a Maven project RUN the main class Spring Boot starts the app and the built-in web server ```
