HTML, CSS and JavaScript: Course Introduction

Instructor: Michelle Saltoun, with a team of IBM and industry experts. Goal: learn the fundamental skills needed to develop web applications.

What the course is saying

The instructor quotes the US Bureau of Labor Statistics: employment of web developers is projected to grow 30% from 2021 to 2031, much faster than the average for all occupations. Demand covers many industries, from e-commerce stores to education platforms.

The course has three parts. HTML covers the history and purpose of HTML, the DOM tree, how HTML uses APIs and browser scripting. CSS covers formatting HTML elements and comparing CSS frameworks, then HTML5 structural elements and input attributes. JavaScript covers syntax, common DOM objects, control statements, variables, custom objects, functions, prototypes, client-side JavaScript with HTML, common APIs, and changing inline styles and attributes. Experts also share best practices for HTML5 and JavaScript.

Labs and final project

Labs: fix HTML errors and add missing tags, improve a web application's look with CSS, write a JavaScript simple interest calculator, and test a web application. Final project: a peer-reviewed single-page portfolio website, plus evaluating other learners' submissions. The instructors suggest publishing the portfolio on GitHub Pages (pages.github.com).

The course is for everyone: IT people, fresh graduates, or complete beginners. Watch the videos, do the quizzes, use the discussion forums, and finish the hands-on parts to build a portfolio for future employers.

Logic: how the three parts fit

HTML  = the structure (what is on the page)
CSS   = the look (how it is styled)
JavaScript = the behaviour (what happens when I click)

BUILD a web page:
    WRITE the HTML structure first
    ADD CSS to style it
    ADD JavaScript so it responds to the user
    TEST in the browser
    PUBLISH to GitHub Pages

Real-life example

Think of a banking app's loan screen. HTML is the form itself, with the labels, the amount box and the Calculate button. CSS is the colours, fonts and spacing that make it look like a bank. JavaScript is what runs when the customer presses Calculate and the interest is worked out. The simple interest calculator lab is exactly this.

Tips for understanding

  • Always ask which of the three jobs a line of code is doing: structure, look or behaviour.
  • Build in that order. A page with no CSS or JavaScript still works.
  • Use the browser's inspect tool to see the DOM tree of any site you visit.
  • Start your portfolio page early and improve it after each module.
