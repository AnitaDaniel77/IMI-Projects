Introduction to HTML

What the instructor is teaching

HTML stands for HyperText Markup Language, often called the language of the internet. It was first designed for sharing scientific documents and was adapted over the years to describe many other kinds of pages. Elements are the building blocks of a page. Each piece of content gets a label such as paragraph, list or table, and those labels are written as tags. The browser does not show the tags. It uses them to decide how to display the content.

HTML was introduced in the early 1990s through CERN and the IETF. The W3C made recommendations over the years, and WHATWG worked on its own at first. In 2007 the W3C formed a working group to work with WHATWG on HTML5, and both groups have developed it together since.

Objectives of HTML5

  • One language, HTML5, that can be written in HTML or XML syntax.
  • A processing model that works with earlier HTML implementations.
  • Better markup for documents.
  • Markup and APIs for web storage, video and audio.

In this course, "HTML" means HTML5 unless the instructor says otherwise. The full term HTML5 is used to separate it from older versions or to talk about features new to HTML5.

Logic

Content (text, list, table)
    -> give each piece a label (paragraph, list, table)
    -> write the label as a tag around the content
    -> browser reads the tags
    -> browser shows the content formatted, without showing the tags

Real-life example

Think of a bank statement. The account name is a heading, the explanation is a paragraph, the list of fees is a list, and the transactions are a table. Someone has labelled each part so the printer knows how to lay it out. Tags are those labels, and the browser is the printer.

Tips for understanding

  • Ask "what is this content?" before choosing a tag: a paragraph, a list or a table.
  • Most tags come in pairs, an opening and a closing one, with the content between them.
  • Right-click a page in your browser and choose "View page source" to see real tags.
  • If someone says HTML, they almost always mean HTML5.
