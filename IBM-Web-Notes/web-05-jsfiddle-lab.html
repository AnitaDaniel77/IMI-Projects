Lab: Intro to HTML (JSFiddle)

What the lab is teaching

JSFiddle is an online playground where you can write HTML, CSS and JavaScript and see the result live. The lab shows what each of the three does in one page. You cannot break anything there, and you can reopen the original link to start again.

The four areas of JSFiddle

  • HTML area: the tags and the page text.
  • CSS area: colours, fonts and sizes.
  • JavaScript area: the code that makes the page interactive.
  • Preview area: the page as a browser would show it. Click Run after every change to refresh it.

Exercises and what each one shows

  • Exercise 1, HTML: replace "Tom" in the main heading with your name, then change the text in the p tag and in the div. This shows HTML provides the content and markup.
  • Exercise 2, CSS: change the background colour from tan to grey (blue, red, green, lightblue and yellow also work), change the paragraph font from arial to times, and change the div width to 400px. This shows CSS controls the look.
  • Exercise 3, JavaScript: change the Wish message to "Good Day", then try a Spanish greeting. Then change the button text to "Show Time" and the function call from hello() to showtime(), so the button shows the current time. This shows JavaScript controls the behaviour. If no alert appears, allow pop-ups for the site.

Logic

EDIT the HTML, CSS or JavaScript area
CLICK Run
PREVIEW refreshes

WHEN the user clicks a button:
    the onclick names a function
    the function runs
    the alert shows a message or the current time

Real-life example

It is like designing a bank app screen. HTML places the heading and the button, CSS makes it look like the bank's brand, and JavaScript decides what happens when the customer taps the button, such as showing a balance message. Run is the "refresh" so you can see your changes straight away.

Tips for understanding

  • Change one thing at a time and click Run, so you know what caused what.
  • Ask which area a change belongs in: content, look or behaviour.
  • A button calls a function by name in onclick, so if the name does not match, nothing happens.
  • Do the exercises yourself in JSFiddle first, then compare with the code file.
