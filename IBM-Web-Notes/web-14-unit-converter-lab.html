Lab: Unit Conversion using HTML5 Structural Elements

IBM HTML, CSS and JavaScript course, Module 2 hands-on lab. Built a unit converter page with three sections: Celsius to Fahrenheit, kilograms to pounds and kilometres to miles. Code is in web-14-code.html.

What the lab covers

The lab uses the structural elements from the lecture on one real page: header, nav, section, article, figure and figcaption, aside and footer. The page only has the layout so far. The Convert buttons do nothing yet, because the calculation script and the styling come later in the course.

How the page is built

The page has a top block (home) with a title and a menu of three buttons. Under it sits a wrapper holding three sections, one per conversion. Each section is built the same way: a figure with a picture and caption on top, an article holding the form fields, and an aside with the formula so the user can do the sum by hand. At the bottom there is a home button that jumps back to the top, and a footer.

Real-life example: this is a currency converter on a banking site. The menu buttons are the tabs (Rand to Dollar, Rand to Euro, Rand to Pound). Each tab has a picture, an input for the amount, a Convert button and an output. The side note says "Rand amount divided by the exchange rate", so the customer can check the answer.

How the in-page links work

Each menu button sits inside a link that points to a section's id with a hash in front. Clicking it scrolls the page to the element with that id. The home button at the bottom does the same thing back to the top section. This only works when each id is unique on the page.

Logic

Build from the outside in. First the shell of the page, then the top block, then one converter fully, then copy its structure for the next two. The three converters are identical except for the labels, the picture and the formula, so once one works the others are copy and change.

Pseudocode

START page
    top block (home)
        header: "Unit Conversions"
        navigation
            button to Temperature section
            button to Weight section
            button to Distance section

    wrapper for all converters
        FOR each of Temperature, Weight, Distance
            section with its own unique id
                group
                    figure: picture and caption
                    article
                        fieldset with a legend
                            label and number input (the value to convert)
                            Convert button
                            number input (the result) and its label
                    aside: formula for doing it by hand

    home button: link back to the top block
    footer: course message
END page

FORMULAS (used later when scripting is added)
    fahrenheit = celsius x 9 / 5 + 32
    pounds = kilograms x 2.205
    miles = kilometres / 1.609

Tips for understanding the logic

  • Read the page by its element names only. Header, nav, section, article, aside, footer should tell the story of the page without reading any text.
  • Every id must be unique. The lab reuses the words temperature, weight and distance as both a section id and a button id. The links still work because the section comes first, but the scripts added later would grab the wrong element. In my code the buttons have their own ids.
  • A label's for must match its input's id. Click the label text. If the cursor jumps into the field, it is wired correctly.
  • Build one converter completely and check it in Live Server before copying it. A mistake copied three times is three fixes.
  • Always give images alt text, so a broken image link or a screen reader still says what the picture is.
