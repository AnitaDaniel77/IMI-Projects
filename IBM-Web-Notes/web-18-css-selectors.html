CSS Selectors: Tags, IDs and Classes

What a selector is

A selector is the pattern in a CSS rule that says which HTML elements the rule applies to. It sets up the link between the elements on the page and the styles applied to them. Selectors matter because they let you target exactly the elements you mean, which keeps the design consistent across the site.

Real-life example: a branch manager's memo says "all tellers wear the blue shirt" (a tag), "the person at desk 3 wears a name badge" (an id) and "everyone on the fraud team wears a red lanyard" (a class). The memo works because each phrase picks out exactly the people it means.

The three selectors

TagThe HTML tag name on its ownEvery element of that tag on the pageAll h1 headings get a blue colour and a font size of 24 pixels

ClassA dot, then the class nameEvery element with that class. Many elements can share a class.All elements with class highlight get a yellow background and dark text

When to use which

Use a tag selector to style a whole group in one go, such as every paragraph. Use an id for the one-of-a-kind element, such as the page header or the logo. Use a class for a pattern you want to reuse on different elements, such as a warning box or a highlighted row. In the same way, one banking page might style all table rows alike (tag), the one account balance box differently (id) and every fraud alert in the same red (class).

Priority when rules clash

This part goes beyond the reading but explains most "why is my style not working" moments. When two rules from the same layer target one element and set the same property, the more specific selector wins. An id is more specific than a class, and a class is more specific than a tag. If they are equally specific, the rule that appears later in the file wins.

Logic

For each thing you want to style, ask: how many elements is this for? All of one kind: tag. Exactly one: id. Some, scattered around the page: class. Write the rule with the matching symbol and put the style properties in the braces.

Pseudocode

RULE TYPE 1: tag selector
    selector = the tag name (no symbol)
    applies to = every element with that tag
    example: all h1 headings -> blue, 24 pixels

RULE TYPE 2: id selector
    selector = hash symbol + id
    applies to = the single element with that id
    example: element with id "header" -> light grey background, 10 pixels padding

RULE TYPE 3: class selector
    selector = dot + class name
    applies to = every element listing that class
    example: elements with class "highlight" -> yellow background, dark text

WHEN two rules set the same property on one element
    IF one selector is more specific
        use the more specific one (id, then class, then tag)
    ELSE
        use the one that comes later in the file

Tips for understanding the logic

  • Read the symbol first. No symbol is a tag, a hash is an id, a dot is a class.
  • An id belongs to one element. If you want the same look on a second element, you needed a class.
  • An element can have more than one class. Separate them with a space in the class attribute and the element gets the styles of all of them.
  • If a style does not show, check three things in order: the spelling of the id or class in both files, the symbol in front of it, and whether a more specific rule is overriding it.
  • Do not use ids for styling everything. Classes are easier to reuse and harder to get into a fight with.
