JavaScript Data Types and Variables

What a variable is

A variable is a named storage location that holds a value you can use later in your code. You declare it (reserve a spot in memory) with var, let or const, and you can optionally give it a starting value at the same time. That first assignment is called initialization.

Banking example: a variable is a labelled account. The label is "savingsBalance" and the money inside is the value. You can look at it, add to it, or pay from it.

The three keywords

var

The original way. It has function-level scope, so a var is visible everywhere inside the function where it was declared, even outside the block it sits in.

let

Introduced in ES6. It has block-level scope, so it only exists inside the curly braces where it was declared. It can be reassigned but not redeclared in the same block. This is more predictable and causes fewer bugs.

const

Also from ES6, with block-level scope. Once it has a value you can't reassign it or redeclare it. Use it for values that shouldn't change, like a fixed fee or a constant.

Banking example: var is a key that opens every room in the branch. let is a key for one room only. const is a sealed envelope: you can read it, but you can't swap what's inside for something else.

Naming rules

A name must start with a letter, an underscore or a dollar sign. After that it can contain letters, numbers, underscores and dollar signs. Names are case sensitive, so balance and Balance are two different variables.

Data types

JavaScript is dynamically typed. You don't state the type when you declare a variable, because it's worked out at runtime from the value you assign. The same variable can later hold a different type.

Primitive types

String is text in single or double quotes. Number covers whole numbers and decimals. Boolean is true or false. Undefined means declared but with no value yet. Null means an empty value, set on purpose.

Composite types

These hold several values as one unit. An array is a list of values. An object is a collection of key and value pairs.

Banking example: string is the account holder's name. Number is the balance. Boolean is "isActive". Undefined is a new account whose limit hasn't been set. Null is "no linked card". An array is the list of the last five transactions. An object is one customer record with name, id and balance.

Logic and pseudocode

DECLARE const bankName = "Capitec"
DECLARE let balance = 1000
DECLARE a variable with no value (it is undefined)

IF something is true
  DECLARE let and var inside the block
  AFTER the block
    let is gone, var is still available

TRY to change bankName
  ERROR, const cannot be reassigned

CHANGE balance to 1500, this is fine

STORE a list of amounts in an array
STORE name, id and balance in an object
SHOW the type of each value

Tips for understanding

  • Default to const. Switch to let only when you know the value will change. Avoid var in new code.
  • Ask "where can I still use this variable?" That's scope. Curly braces are the boundary for let and const.
  • Use typeof to check what a value is when the result surprises you.
  • const stops reassignment, not change inside an array or object. You can still add an item to a const array.
  • undefined means nobody gave it a value. null means somebody emptied it on purpose.
