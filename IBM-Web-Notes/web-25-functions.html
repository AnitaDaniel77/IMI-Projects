JavaScript Functions and Types of Functions

What a function is

A function is a reusable block of code. You write it once, give it a name, and run it as many times as you need. This keeps code organised, easier to read and easier to maintain. You declare it with the function keyword, a name, parentheses and curly braces holding the code. You run it by calling its name followed by parentheses.

Banking example: a function is a standard procedure at the branch, like "print a statement". The teller doesn't invent the steps each time. They follow the same procedure for every customer.

Non-parameterized and parameterized

A non-parameterized function takes no input. It does its job on its own, like showing a welcome message. A parameterized function takes one or more inputs, so the same function can work with different values.

Banking example: "show the bank's opening hours" needs nothing from you. "Calculate the fee on this amount" needs the amount.

Parameters and arguments

Parameters are the variables listed in the function declaration. Arguments are the actual values you pass in when you call it. In add(a, b), a and b are parameters. In add(3, 4), the values 3 and 4 are arguments.

Banking example: the parameter is the empty "amount" box on a deposit slip. The argument is the R500 you write in it.

Two ways to write a function

Function declaration

The traditional way. Use the function keyword, then the name and parameters.

Function expression

Create the function and store it in a variable. You call it using the variable's name.

Types of functions

Named function

Has a name, so you call it by that name. Names also appear in the call stack when something breaks, which helps with debugging.

IIFE (immediately invoked function expression)

Defined and run straight away. It keeps its variables in a private scope, so they don't clash with other code or pollute the global scope.

Arrow function

A shorter way to write a function, introduced in ES6. Good for short, simple functions.

Anonymous function

Has no name. Often passed to another function as an argument or stored in a variable. An arrow function without a name is an anonymous function too.

Banking example: a named function is a staff member with a name badge. An IIFE is a one-time check done the moment a branch opens. An arrow function is a quick shorthand note. An anonymous function is a temporary worker who does one job and has no badge.

Logic and pseudocode

DEFINE showWelcome (no input)
  SHOW "Welcome to the bank"

DEFINE calculateFee (amount)
  fee = amount times 0.01
  GIVE BACK fee

CALL showWelcome
CALL calculateFee with 500
  SHOW the result

STORE a function in a variable (function expression)
CALL it using the variable name

WRITE a short version using an arrow
RUN a function the moment it is created (IIFE)
PASS an unnamed function to another function

Tips for understanding

  • Think "define now, run later". Declaring a function doesn't run it. Only the call does.
  • If a function shows nothing, check you called it. Forgetting the parentheses is a common miss.
  • Use return when you want a value back. Without it the function gives back undefined.
  • Give functions verb names like calculateFee, so the name says what it does.
  • Read an arrow function from left to right: inputs, arrow, result.
