web-32: Single Page Portfolio Website (Coursera final project)

What the project is

A one-page portfolio built on a starter: HTML for the structure, CSS for the look, and a little JavaScript for the recommendation form. The job was to personalise the starter and fix the small gaps, then prove each change with screenshots. Result: 19/20 (95%).

Real-life example: the starter is a furnished flat. You don't build walls, you put your name on the door, hang your photo, and fix the things that don't work yet.

The tasks, in order

  1. Profile: put my name, a pseudo email and a pseudo phone number in the top-left of the purple bar.
  2. Navigation: four links (About Me, Project Details, Skills, Recommendations), each pointing at a section id, with bold and underline on hover.
  3. About Me: my own photo and an updated intro paragraph.
  4. Skills: five skill cards, each with a logo, a name and the experience line.
  5. Projects: three projects with a heading and one bullet each.
  6. Recommendations: three tiles in the starter's quote format.
  7. Form: Submit adds the typed message as a new tile.
  8. Popup: a thank-you box that appears after a valid submit, closed with Ok.
  9. Home icon: the round arrow button that jumps back to the top.

How the pieces connect

Every nav link uses href="#something". The browser looks for the element with that id and scrolls to it, so the link text and the section id have to match exactly. The home icon works the same way, pointing at the id of the nav bar at the top.

Real-life example: the nav bar is a building directory. "Skills, floor 3" only works if floor 3 actually has that name on its door.

The form does three things in a row: read the textarea, build a new tile, show the popup. An empty message does nothing, so the popup only appears when there is something to add.

Real-life example: a suggestion box with a clerk who throws away blank slips, and only rings the bell when a real one drops in.

Pseudocode

Adding a recommendation:

``` WHEN Submit is clicked: text = value of the Message box IF text is empty: do nothing ELSE: tile = new div with class "recommendation" tile content = opening quote + text + closing quote add tile to the end of the recommendations list clear the Message box show popup ```

Popup:

``` showPopup(visible): IF visible is true: make the popup visible ELSE: hide the popup Ok button calls showPopup(false) ```

Tips for understanding the logic

  • Read the page top to bottom and ask of each section, "what id does it have, and which link points at it?"
  • If a link does nothing, compare the href and the id letter by letter. Case matters.
  • If an image is blank, check the path and the exact file name. Anita.jpeg is not anita.jpg on GitHub or in the lab.
  • If the popup never shows, check that showPopup(true) is called inside the branch that handles a non-empty message.
  • Change one thing, refresh, look. Don't edit five things and then refresh.

Problems I hit

  • Photo path mismatch (jpg versus jpeg). Fixed by matching the real file name.
  • Photo was blurry and too big. Fixed by giving it a fixed width and height with object-fit: cover.
  • Skill cards were cut off in screenshots. Fixed by zooming the browser out before capturing.
