1. What is H2?

H2 is a lightweight open-source SQL database written in Java. It runs inside your app (embedded) or as a small local server.

Real-life example: think of it as a notebook that sits right next to your Java program - you write product lists into it and read them back later, no big library building required.

Two modes:

  • File-backed - data saved on disk, survives restart (what PayNest uses)
  • In-memory - data lives only while the app runs, then disappears

PayNest JDBC URL:

jdbc:h2:file:./data/paynest;AUTO_SERVER=TRUE;TRACE_LEVEL_FILE=3

3. SQL schema shown - products table

CREATE TABLE IF NOT EXISTS products (
    id    INT PRIMARY KEY,     -- unique row identifier
    name  VARCHAR(100) NOT NULL, -- product name, required
    price DOUBLE NOT NULL        -- product price, required
);

Real-life example: this is like designing a stock ledger page before you write anything in it - id is the row number, name and price are the two columns you're not allowed to leave blank.

Hilbert pointed out that DBeaver is reading the same database, not a separate copy:

  • data file: data/paynest.mv.db - the real tables/rows
  • trace file: data/paynest.trace.db - SQL debug log, not the database itself

Real-life example: the trace file is like a security camera log of what happened at the bank, not the vault itself - useful for debugging, but it's not where your money actually lives.
